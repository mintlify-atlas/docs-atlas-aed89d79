---
title: "Protection domains"
description: "Allocating and freeing Protection Domains"
---

A Protection Domain (PD) is a container that groups related RDMA resources — memory regions, queue pairs, shared receive queues, and address handles — and enforces access isolation between them. Resources registered or created in one PD cannot be used with resources from a different PD. Every application that uses libibverbs must allocate at least one PD before creating any other resource.

```c
#include <infiniband/verbs.h>
```

---

## Overview

Protection domains provide the following guarantees:

- A memory region (MR) is always associated with exactly one PD. Remote operations using that MR's `rkey` are validated against the PD.
- A queue pair (QP) must be created under a PD. Send work requests may only reference scatter/gather elements whose `lkey` belongs to the same PD.
- An address handle (AH) must belong to a PD and can only be used in send requests on a QP from the same PD.

When `ibv_dealloc_pd` is called, the call fails if any resource is still associated with the PD. All QPs, MRs, SRQs, and AHs under the PD must be destroyed first.

---

## ibv_alloc_pd

Allocates a new Protection Domain.

**Signature:**

```c
struct ibv_pd *ibv_alloc_pd(struct ibv_context *context);
```

**Parameters:**

<ParamField path="context" type="struct ibv_context *">
  An open device context returned by `ibv_open_device`.
</ParamField>

**Returns:** A pointer to the newly allocated `struct ibv_pd`, or `NULL` on failure (with `errno` set).

**Example:**

```c
struct ibv_pd *pd = ibv_alloc_pd(ctx);
if (!pd) {
    perror("ibv_alloc_pd");
    return 1;
}
```

---

## ibv_dealloc_pd

Frees a Protection Domain.

**Signature:**

```c
int ibv_dealloc_pd(struct ibv_pd *pd);
```

**Parameters:**

<ParamField path="pd" type="struct ibv_pd *">
  The protection domain to deallocate.
</ParamField>

**Returns:** `0` on success, or a positive `errno` value on failure.

**Errors:** Returns `EBUSY` if any resource (MR, QP, SRQ, AH) is still associated with the PD.

<Warning>
  Destroy all memory regions, queue pairs, shared receive queues, and address handles that belong to this PD before calling `ibv_dealloc_pd`, or the call will fail.
</Warning>

---

## ibv_alloc_parent_domain

Allocates a parent domain, which extends a basic PD with a thread domain and optional application context. Parent domains are used with the extended QP API (`ibv_create_qp_ex`) to enable thread-safe, lockless send queues.

**Signature:**

```c
struct ibv_pd *ibv_alloc_parent_domain(
        struct ibv_context *context,
        struct ibv_parent_domain_init_attr *attr);
```

**Parameters:**

<ParamField path="context" type="struct ibv_context *">
  An open device context.
</ParamField>

<ParamField path="attr" type="struct ibv_parent_domain_init_attr *">
  Initialization attributes. Set `attr->pd` to the underlying basic PD and `attr->td` to a thread domain allocated with `ibv_alloc_td`. Set `attr->comp_mask` to indicate which fields are valid.
</ParamField>

**Returns:** A `struct ibv_pd *` that can be used wherever a regular PD is accepted, or `NULL` on failure.

<Note>
  Not all drivers support parent domains. If the driver returns `EOPNOTSUPP`, fall back to a regular PD. Check `attr->comp_mask` for capability flags.
</Note>

## Full lifecycle example

```c
#include <infiniband/verbs.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    /* 1. Enumerate and open device */
    int num_devices;
    struct ibv_device **dev_list = ibv_get_device_list(&num_devices);
    if (!dev_list || num_devices == 0) {
        fprintf(stderr, "No RDMA devices found\n");
        return 1;
    }

    struct ibv_context *ctx = ibv_open_device(dev_list[0]);
    ibv_free_device_list(dev_list);
    if (!ctx) {
        perror("ibv_open_device");
        return 1;
    }

    /* 2. Allocate a PD */
    struct ibv_pd *pd = ibv_alloc_pd(ctx);
    if (!pd) {
        perror("ibv_alloc_pd");
        ibv_close_device(ctx);
        return 1;
    }

    /*
     * 3. Create resources (MRs, QPs, AHs) under pd
     *    ...
     */

    /* 4. Destroy all resources before deallocating PD */
    if (ibv_dealloc_pd(pd)) {
        perror("ibv_dealloc_pd");
    }
    ibv_close_device(ctx);
    return 0;
}
```
