---
title: "rdma-core"
description: "Userspace libraries and daemons for the Linux RDMA subsystem — enabling high-performance InfiniBand, iWARP, and RoCE networking from userspace."
---

rdma-core provides the complete userspace stack for Linux RDMA hardware. It includes the `libibverbs` C library for direct verbs access, `librdmacm` for connection management, Python bindings via `pyverbs`, hardware provider plugins for 18+ NIC families, and supporting daemons for production deployments.
